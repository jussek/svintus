# Проверка правил

Источник: предоставленный `svintus-rules.pdf`. Документ используется как описание настольной игры. Настройки онлайн-версии определены запросами пользователя.

Изменения по запросу пользователя:

- Без «Перехрюка»: 104 карты, движение только по часовой стрелке.
- От 2 до 6 участников, включая ботов.
- Первый игрок без карт выигрывает раунд. Каждая оставшаяся карта даёт одно штрафное очко её владельцу; игроки с максимальным остатком становятся свинтусами. Следующий раунд начинается с нуля.
- «Свинтус!» объявляется беззвучной кнопкой после предпоследней карты. Если соперник первым нажал «Поймать!» до следующего хода, штраф составляет три карты.
- Ограничения времени на ход полностью отменены. У «Хлопкопыта» тоже нет автоматического завершения: игра ждёт всех, штраф получает фактически последний.

Проверены исходные механики:

| Правило PDF | Реализация и проверка |
| --- | --- |
| По 8 карт; первый ход слева от раздающего | Раздача без повторений, раздающий меняется между раундами; карты сохраняются в партии |
| Первая открытая карта считается сыгранной раздающим | Предписания срабатывают; при первом «Полисвине» раздающий выбирает цвет, остальные ждут |
| Совпадение цвета или достоинства | Сервер проверяет цвет/число/вид; «Полисвин» допустим на обычную карту даже при наличии других подходящих карт |
| Взять одну карту и при желании сыграть её | После взятия можно сыграть только новую карту или завершить ход; неподходящая карта автоматически передаёт ход |
| Перехват точной копией | Вне очереди требуется тот же цвет, вид и число; следующий ход продолжается от перехватившего |
| «Хапёж» | Три карты и пропуск; перевод картой любого цвета того же вида складывает штраф |
| «Захрапин» | Пропуск одного хода; перевод передаёт пропуск следующему игроку |
| «Полисвин» | Выбор любого из четырёх цветов, в том числе прежнего |
| «Тихохрюн» | До следующей сыгранной карты автора или нарушения; нарушитель получает две карты, ход сохраняется |
| «Хлопкопыт» | Все участники отвечают, только последний получает две карты; повторы не учитываются |
| Неправильный ход | Карта остаётся в руке, две штрафные карты и пропуск; накопленный «Хапёж» также принимается |
| Колода закончилась | Перемешивается сброс без верхней карты |
| Последняя карта | Раунд заканчивается немедленно, предписание последней карты не продлевает игру |

Проверки включают партии на двоих, перевод обратно автору, одинаковые карты у нескольких игроков, одновременные действия через сравнение версии комнаты, скрытые руки и сохранение 104 уникальных карт. Боты используют те же серверные правила. Старые сохранённые таймеры удаляются при чтении комнаты без штрафов и смены хода.
