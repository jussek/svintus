# Свинтус онлайн

Игра для **ровно шести человек** с картами из предоставленного набора. «Перехрюк» исключён; колода содержит 104 карты. Каждый получает восемь карт. Направление игры — по часовой стрелке.

Раунд выигрывает первый, кто избавится от всех карт. Каждая оставшаяся карта даёт её владельцу одно штрафное очко. Игрок с наибольшим числом очков становится свинтусом; при равенстве отмечаются все такие игроки. Очки относятся к текущему раунду, следующий раунд начинается с нуля.

## Как играть

Создайте комнату, выберите время хода (2, 3 или 5 секунд), отправьте приглашение пяти друзьям. Когда все места заняты, хозяин раздаёт карты. Регистрация не требуется; место сохраняется в этом браузере. Повторная попытка входа после потери ответа возвращает прежнее место. Комната действует 24 часа.

- Кладите карту того же цвета или достоинства; «Полисвин» позволяет выбрать цвет. Можно взять одну карту и сразу сыграть её, если она подходит.
- Точную копию верхней карты можно сыграть вне очереди. «Хапёж» и «Захрапин» переводятся картой того же вида любого цвета.
- После предпоследней карты нажмите **«Свинтус!»**. Пока следующий игрок не сделал ход, соперник может нажать «Поймать!». Если его действие поступило первым, вы берёте три карты. Кнопка является беззвучным жестом и разрешена при «Тихохрюне».
- При «Хлопкопыте» все нажимают **«Хлоп!»**. Последний получает две карты. Не нажавшие до окончания времени считаются последними одновременно и получают по две карты.
- «Тихохрюн» запрещает сообщения до следующей сыгранной карты его автора. Сообщение или кнопка нарушения тишины дают две карты и снимают запрет. Речь во внешнем созвоне участники контролируют сами.
- Просроченный ход и неправильная карта дают две карты и пропуск хода. Накопленный «Хапёж» при этом также нужно принять.

## Разработка

Нужен Node.js 24 и npm. Используйте существующий checkout; отдельный Git worktree для облачной задачи не требуется.

```sh
npm ci
npm run dev
```

Сервер читает `SUPABASE_URL` и `SUPABASE_SECRET_KEY` (либо legacy `SUPABASE_SERVICE_ROLE_KEY`). В облачной среде используйте уже подключённые переменные. Для локальной машины создайте `.env.local` по `.env.example`; секреты в Git не добавляйте. В средах с HTTP-прокси и Node.js 24 включите `NODE_USE_ENV_PROXY=1` при запуске.

```sh
npm test
npm run typecheck
npm run build
npm start
```

`GET /api/health` проверяет подключение к хранилищу. Функциональная проверка сервера и базы:

```sh
BASE_URL=http://127.0.0.1:3000 node scripts/smoke.mjs
npm run test:e2e
```

Тесты создают собственные комнаты и удаляют только их. Для браузерных тестов доступен Chromium: задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` или установите браузер командой `npx playwright install chromium`.

## Supabase и Vercel

Схема находится в `supabase/migrations/20261010000000_rooms.sql`. Таблица `svintus_rooms` закрыта для браузерных ключей: RLS включён, доступ имеет только сервер. Руки игроков и хеши сессий сохраняются на сервере. Клиент получает свою руку и количество карт у соперников.

Все ходы сервер проверяет заново. Обновление комнаты использует атомарное сравнение `version`; одновременные перехваты и гонка «Свинтус!»/«Поймать!» разрешаются по первому принятому действию. `X-Action-Id` предотвращает повторное выполнение одного запроса. Клиенты опрашивают сервер каждые 900 мс; таймеры проверяются сервером при запросах.

На Vercel нужны server-only переменные `SUPABASE_URL` и `SUPABASE_SECRET_KEY`. Проект использует Next.js. Публичный ключ Supabase приложению не нужен; секретный ключ никогда не передаётся браузеру. Настройка через официальные API выполняется `node scripts/platform.mjs provision` с уже подключёнными `SUPABASE_ACCESS_TOKEN` и `VERCEL_TOKEN`.

Для повторного деплоя используйте интеграцию GitHub проекта Vercel или Vercel CLI с авторизацией в вашем аккаунте. Production-ветка — `main`. После деплоя проверьте `/api/health` и выполните smoke-тест с `BASE_URL`, равным адресу опубликованной игры.

Карточные изображения предоставлены пользователем. Оригинальный PDF использован как источник механик; правила раундовых очков и кнопки «Свинтус!» изменены по запросу пользователя.
